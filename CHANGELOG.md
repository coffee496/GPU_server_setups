
# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-11-25

### Added

- Initial release.
- Interactive Python version selection (3.10, 3.11, 3.12).
- Automated Python virtual environment setup.
- Automatic detection and activation of existing virtual environments.
- Protection against overwriting existing virtual environments.
- LF line ending configuration for shell scripts.
- README and CHANGELOG documentation.
- Google Classroom reference links in README.
